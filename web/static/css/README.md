# CSS 文件结构说明

## 📁 文件组织

本项目的CSS样式已按照功能模块进行拆分，提高代码的可维护性和可读性。

### 🎯 主要文件

#### 1. **main.css** - 主样式文件
- 导入所有模块化CSS文件
- 作为样式的统一入口点

#### 2. **base.css** - 基础样式
- 重置样式 (`*` 选择器)
- 基础布局 (`.container`, `.main`)
- 通用卡片样式 (`.card`)
- 即将推出页面样式

#### 3. **navigation.css** - 导航样式
- 头部导航 (`.header`)
- 侧边栏菜单 (`.sidebar`, `.sidebar-menu`)
- 响应式侧边栏布局

#### 4. **layout.css** - 布局样式
- 系统内容区域 (`.system-content`)
- 内容区域样式 (`.content-area`)
- 响应式布局适配

#### 5. **components.css** - 组件样式
- 表单控件 (`.row`, `label`, `.control-lg`)
- 按钮样式 (`.btn`, `.btn-*`)
- 网格布局 (`.grid`, `.grid-*`)
- 状态显示 (`.status`)
- 图标按钮 (`.btn-icon`)

#### 6. **tasks.css** - 任务管理样式
- 任务头部 (`.tasks-header`)
- 搜索和控件行 (`.search-row`, `.control-row`)
- 任务内容区域 (`.tasks-content`, `.subtasks`)
- 任务表格 (`.subtasks-table`)
- 状态徽章 (`.badge`)
- 任务状态栏 (`.task-status-bar`)
- 响应式高度优化

#### 7. **tables.css** - 表格样式
- 表格基础样式 (`.subtasks-table`)
- 分页控件 (`.pagination-controls`)
- 状态徽章 (`.badge`)
- 拖拽调整列宽 (`.drag`)
- 编辑界面样式 (`.subtask-bd`)

#### 8. **utilities.css** - 工具样式
- 信息框 (`.info-box`)
- 历史列表 (`.history-list`)
- Toast提示 (`.toast`)
- 网格布局 (`.list-wrap`, `.list-grid`)
- 列表行样式 (`.list-row`)

## 🔧 使用方法

### 开发时
- 修改对应模块的CSS文件
- 主文件会自动导入所有模块

### 生产环境
- 可以合并所有CSS文件为一个文件
- 减少HTTP请求数量

## 📱 响应式设计

- **大屏幕 (≥1200px)**: 完整布局
- **中等屏幕 (≤768px)**: 侧边栏变为水平布局
- **小屏幕 (≤480px)**: 紧凑布局
- **高度适配**: 针对不同屏幕高度优化任务区域

## 🎨 设计系统

### 颜色方案
- **主色**: `#3b82f6` (蓝色)
- **成功色**: `#10b981` (绿色)
- **警告色**: `#f59e0b` (橙色)
- **错误色**: `#ef4444` (红色)
- **中性色**: `#64748b`, `#94a3b8`

### 间距系统
- **基础间距**: `8px`, `12px`, `16px`, `20px`, `24px`
- **响应式间距**: 根据屏幕尺寸自动调整

### 圆角系统
- **小圆角**: `4px`, `6px`
- **中圆角**: `8px`, `10px`
- **大圆角**: `12px`

- 模块化加载，按需引入
- CSS选择器优化，避免深层嵌套
- 响应式媒体查询优化
- 滚动条样式自定义
