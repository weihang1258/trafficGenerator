# 🚀 流量生成器 - Web界面测试指南

## 📁 文件结构

```
web/static/
├── index.html              # 主页面
├── styles.css              # 样式文件
├── common.js               # 通用功能模块
├── overview_simple.js      # 概览页面功能（简化版）
├── tasks_simple.js         # 任务管理功能（简化版）
├── pcap.js                 # PCAP文件管理
├── history.js              # 历史配置管理
├── settings.js             # 系统设置
├── debug_test.html         # 调试测试页面
├── simple_test.html        # 简单功能测试
└── test.html               # 完整功能测试
```

## 🧪 测试页面说明

### 1. **debug_test.html** - 调试测试页面（推荐）
- **功能**: 全面的功能测试和调试
- **特点**: 实时状态监控、详细日志、错误捕获
- **用途**: 开发调试、功能验证、问题排查

### 2. **simple_test.html** - 简单功能测试
- **功能**: 基本功能验证
- **特点**: 简洁的测试界面
- **用途**: 快速功能检查

### 3. **test.html** - 完整功能测试
- **功能**: 完整功能测试套件
- **特点**: 全面的测试覆盖
- **用途**: 系统集成测试

## 🌐 访问方式

### 启动HTTP服务器
```bash
# 在 web/static 目录下执行
cd web/static
python -m http.server 8080
```

### 访问测试页面
- **调试测试**: http://localhost:8080/debug_test.html
- **简单测试**: http://localhost:8080/simple_test.html
- **完整测试**: http://localhost:8080/test.html
- **主页面**: http://localhost:8080/index.html

## 🧪 测试流程

### 1. **基本功能测试**
- 检查所有函数是否正常加载
- 验证页面切换功能
- 测试Toast提示系统

### 2. **任务功能测试**
- 添加测试任务
- 验证任务列表渲染
- 测试搜索过滤功能

### 3. **页面切换测试**
- 测试各页面间的切换
- 验证页面特定功能初始化

### 4. **WebSocket测试**
- 测试连接建立
- 验证消息处理
- 检查重连机制

## 🐛 常见问题排查

### 1. **文件404错误**
- 确保HTTP服务器在正确的目录下启动
- 检查文件名是否正确
- 验证文件权限

### 2. **JavaScript错误**
- 打开浏览器开发者工具
- 查看Console面板的错误信息
- 检查网络面板的文件加载状态

### 3. **功能异常**
- 使用debug_test.html进行详细诊断
- 查看调试日志
- 检查浏览器兼容性

## 📱 浏览器兼容性

- **推荐**: Chrome 80+, Firefox 75+, Safari 13+
- **最低**: Chrome 60+, Firefox 55+, Safari 11+
- **不支持**: IE 11及以下版本

## 🔄 开发流程

1. **修改代码** → 保存文件
2. **刷新浏览器** → 查看效果
3. **使用测试页面** → 验证功能
4. **查看控制台** → 排查问题
5. **重复步骤** → 直到功能正常

## 📞 技术支持

如果遇到问题，请：
1. 查看浏览器控制台错误信息
2. 使用debug_test.html进行诊断
3. 检查文件路径和权限
4. 验证HTTP服务器状态
