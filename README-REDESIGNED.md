# 高性能流量生成器 - 重新设计版本

## 🎯 新版本特性

### 全新的用户界面
- **科技感深色主题** - 专业工具风格，适合长时间使用
- **多系统架构** - 支持流量生成器、报文分析器、性能监控等多个系统
- **响应式设计** - 适配不同屏幕尺寸

### 策略管理系统
- **五元组配置** - 直观显示源IP、目标IP、源端口、目标端口、协议
- **参数策略** - 支持固定、递增、随机、列表、模式等多种生成策略
- **冲突检测** - 自动检测策略间的五元组冲突
- **批量操作** - 支持批量启用、禁用、删除策略

### 任务管理系统
- **策略组合** - 选择多个策略组合成任务
- **全局控制** - 统一的流数总量、执行时间、输出方式配置
- **配置生成** - 自动将策略组合生成JSON配置文件
- **实时监控** - 任务执行状态、进度、统计信息实时更新

### 系统配置
- **服务管理** - 配置生成服务、报文构造服务等的启停控制
- **输出配置** - PCAP文件输出或网卡直接发送
- **性能调优** - 进程数、缓冲区大小、队列容量等参数调整

## 🚀 快速开始

### 1. 依赖安装
```bash
# 最小依赖（通过CDN加载前端资源，无需额外安装）
pip install fastapi uvicorn psutil

# 可选依赖（用于扩展功能）
pip install pandas numpy
```

### 2. 启动服务
```bash
# 启动重新设计的版本
python start-redesigned.py

# 或者直接启动
cd web
python app-redesigned.py
```

### 3. 访问界面
打开浏览器访问: http://localhost:5000

## 📋 使用指南

### 策略管理
1. **创建策略**
   - 点击"策略管理" → "新建策略"
   - 选择协议类型（TCP/UDP/HTTP）
   - 配置五元组参数（IP地址、端口、策略类型）
   - 设置协议特定参数
   - 保存策略

2. **查看策略列表**
   - 支持按名称、协议、五元组信息搜索
   - 支持按创建时间、使用次数排序
   - 支持批量操作（启用/禁用/删除）

### 任务管理
1. **创建任务**
   - 点击"任务管理" → "新建任务"
   - 选择要组合的策略
   - 设置执行参数（流数、时间、输出方式）
   - 系统自动生成JSON配置文件

2. **执行任务**
   - 启动必要的后台服务
   - 单个任务执行或批量执行
   - 实时监控执行状态和进度

### 系统配置
1. **服务管理**
   - 启动/停止配置生成服务
   - 启动/停止报文构造服务
   - 查看服务运行状态

2. **输出配置**
   - 选择PCAP文件输出或网卡发送
   - 配置输出路径和网卡接口
   - 设置性能参数

## 🏗️ 技术架构

### 前端技术栈
- **Vue.js 3** - 渐进式JavaScript框架
- **原生CSS** - 深色主题科技风格
- **ECharts** - 数据可视化图表
- **WebSocket** - 实时数据通信

### 后端技术栈
- **FastAPI** - 现代高性能Web框架
- **Pydantic** - 数据验证和序列化
- **Uvicorn** - ASGI服务器
- **现有流量生成引擎** - 高性能多进程架构

### 数据流设计
```
策略配置 → JSON配置文件 → 流量生成引擎 → PCAP/网卡输出
     ↓
任务管理 → 实时监控 → WebSocket → 前端展示
```

## 🔧 API接口

### 策略管理
- `GET /api/strategies` - 获取策略列表
- `POST /api/strategies` - 创建新策略
- `PUT /api/strategies/{id}` - 更新策略
- `DELETE /api/strategies/{id}` - 删除策略
- `POST /api/strategies/batch` - 批量操作

### 任务管理
- `GET /api/tasks` - 获取任务列表
- `POST /api/tasks` - 创建新任务
- `PUT /api/tasks/{id}/start` - 启动任务
- `PUT /api/tasks/{id}/stop` - 停止任务
- `POST /api/tasks/{id}/refresh-config` - 刷新配置

### 系统控制
- `POST /api/hptg/start` - 启动流量生成器
- `POST /api/hptg/stop` - 停止流量生成器
- `GET /api/hptg/status` - 获取系统状态
- `WebSocket /api/hptg/stream` - 实时状态推送
