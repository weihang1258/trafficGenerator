## 阶段1: 基础架构 (Week 1-2)

### 1.1 项目初始化

- [ ] 创建Go项目结构
  ```
  trafficgen/
  ├── cmd/server/          # 主程序入口
  ├── internal/            # 内部包
  │   ├── api/            # API层
  │   ├── core/           # 核心引擎
  │   ├── protocol/       # 协议插件
  │   └── storage/        # 存储层
  ├── pkg/                # 公共包
  ├── configs/            # 配置文件
  ├── web/                # 前端代码
  └── deployments/        # 部署配置
  ```

- [ ] 初始化go.mod
  ```bash
  go mod init github.com/yourorg/trafficgen
  ```

- [ ] 配置依赖
  - gin-gonic/gin
  - gorm.io/gorm
  - google/gopacket
  - go-redis/redis
  - uber-go/zap
  - prometheus/client_golang

- [ ] 配置golangci-lint
  ```yaml
  # .golangci.yml
  linters:
    enable:
      - gofmt
      - govet
      - errcheck
      - staticcheck
  ```

- [ ] 配置GitHub Actions CI
  ```yaml
  # .github/workflows/ci.yml

  ```
