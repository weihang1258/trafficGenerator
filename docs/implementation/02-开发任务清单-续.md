## 阶段9: 部署 (Week 13-14)

### 9.1 Docker化 (Week 13)

- [ ] 创建 `Dockerfile`
  ```dockerfile
  FROM golang:1.21-alpine AS builder
  WORKDIR /app
  COPY . .
  RUN go build -o server cmd/server/main.go
  
  FROM alpine:latest
  COPY --from=builder /app/server /server
  CMD ["/server"]
  ```
