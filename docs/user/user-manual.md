## 快速开始

### 系统要求

- 操作系统: Linux / Windows / macOS
- 浏览器: Chrome 90+, Firefox 88+, Safari 14+
- 网络: 能够访问目标网络

### 访问系统

1. 打开浏览器，访问系统地址
   - 开发环境: http://localhost:8080
   - 生产环境: https://trafficgen.example.com

2. 登录系统
   - 默认用户名: `admin`
   - 默认密码: `admin`
   - **注意**: 首次登录后请立即修改密码

### 创建第一个任务

1. 点击左侧菜单 "任务管理" → "创建任务"
2. 填写任务信息:
   - 任务名称: `测试任务1`
   - 协议类型: `TCP`
   - 源 IP: `192.168.1.1`
   - 目标 IP: `192.168.1.2`
   - 源端口: `12345`
   - 目标端口: `80`
3. 点击 "创建" 按钮
4. 在任务列表中找到刚创建的任务，点击 "启动" 按钮
5. 查看任务详情和实时统计信息

## 功能说明

### 核心功能

#### 1. 任务管理

**功能描述**: 创建、启动、停止、删除流量生成任务

**支持的协议**:
- **TCP**: 完整的 TCP 流量（握手、数据传输、挥手）
- **UDP**: UDP 数据报流量
- **HTTP**: HTTP/1.1 请求响应流量
- **DNS**: DNS 查询和响应
- **ICMP**: ICMP Echo 请求和响应
- **ARP**: ARP 请求和响应

**任务状态**:
- **待运行**: 任务已创建，等待启动
- **运行中**: 任务正在生成流量
- **已完成**: 任务已完成
- **失败**: 任务执行失败

#### 2. 策略管理

**功能描述**: 保存和管理常用的流量配置模板

**使用场景**:
- 保存常用的测试配置
- 快速创建相同类型的任务
- 分享配置给团队成员

#### 3. 网卡管理

**功能描述**: 查看和管理系统网卡

**信息展示**:
- 网卡名称和 MAC 地址
- IP 地址和子网掩码
- 网卡状态（UP/DOWN）
- MTU 大小
- 端口占用情况

#### 4. 实时监控

**功能描述**: 实时查看任务执行状态和统计信息

**监控指标**:
- 已发送数据包数
- 已发送字节数
- 发送速率（pps）
- 吞吐量（bps）
- 错误率

#### 5. 历史记录

**功能描述**: 查看历史任务记录

**功能**:
- 按时间范围筛选
- 按状态筛选
- 导出数据

### 高级功能

#### 1. 批量任务

**功能描述**: 一次创建多个相似任务

**配置参数**:
- IP 地址范围
- 端口范围
- 并发数量

#### 2. 自定义输出

**输出类型**:
- **网卡输出**: 直接发送到指定网卡
- **PCAP 文件**: 保存为 PCAP 文件
- **空输出**: 仅统计，不实际发送

#### 3. WebSocket 实时更新

**功能描述**: 通过 WebSocket 实时接收任务状态更新

**使用方式**:
```javascript
const ws = new WebSocket('ws://localhost:8080/ws');
ws.onmessage = (event) => {
  const data = JSON.parse(event.data);
  console.log('Task update:', data);
};
```

## 使用指南

### 创建 TCP 流量任务

1. **选择协议**
   - 在任务创建页面，选择协议类型为 "TCP"

2. **配置基本参数**
   - 任务名称: 为任务起一个有意义的名字
   - 源 IP: 数据包的源 IP 地址
   - 目标 IP: 数据包的目标 IP 地址
   - 源端口: 数据包的源端口（1-65535）
   - 目标端口: 数据包的目标端口（1-65535）

3. **配置 TCP 参数**（可选）
   - 序列号: 初始序列号
   - 窗口大小: TCP 窗口大小
   - MSS: 最大分段大小
   - 标志位: SYN, ACK, PSH, FIN 等

4. **配置负载**（可选）
   - 负载大小: 数据负载的字节数
   - 负载内容: 自定义负载内容

5. **选择输出模式**
   - 网卡输出: 选择目标网卡
   - PCAP 文件: 指定文件名

6. **提交创建**
   - 点击 "创建" 按钮完成任务创建

### 创建 UDP 流量任务

1. **选择协议**: UDP
2. **配置基本参数**: 同 TCP
3. **配置 UDP 参数**:
   - 负载大小
   - 负载内容
4. **选择输出模式**
5. **提交创建**

### 创建 HTTP 流量任务

1. **选择协议**: HTTP
2. **配置基本参数**:
   - 源 IP 和目标 IP
   - 目标端口（默认 80 或 443）
3. **配置 HTTP 参数**:
   - 请求方法: GET, POST, PUT, DELETE 等
   - 请求路径: URL 路径
   - 请求头: 自定义 HTTP 头
   - 请求体: POST/PUT 请求体
4. **配置响应**:
   - 状态码: HTTP 响应状态码
   - 响应头: HTTP 响应头
   - 响应体: HTTP 响应体
5. **提交创建**

### 使用策略模板

1. **创建策略**
   - 配置好一个任务
   - 点击 "保存为策略" 按钮
   - 输入策略名称和描述

2. **使用策略**
   - 在任务创建页面，点击 "从策略创建"
   - 选择已保存的策略
   - 根据需要调整参数
   - 提交创建

### 监控任务执行

1. **查看任务列表**
   - 在任务列表页面查看所有任务
   - 可以按状态、协议、时间筛选

2. **查看任务详情**
   - 点击任务名称进入详情页
   - 查看任务配置信息
   - 查看实时统计图表

3. **实时统计**
   - 数据包发送速率
   - 吞吐量变化趋势
   - 错误率统计

### 导出 PCAP 文件

1. **创建任务时选择 PCAP 输出**
   - 输出类型: PCAP 文件
   - 文件名: 指定文件名

2. **任务完成后下载**
   - 在任务详情页点击 "下载 PCAP"
   - PCAP 文件可用 Wireshark 打开分析

## 常见问题

### Q1: 任务启动后没有数据包发送？

**可能原因**:
1. 网卡未正确选择
2. 目标 IP 不可达
3. 权限不足（需要 root 或 CAP_NET_RAW）

**解决方法**:
1. 检查网卡配置，确保选择了正确的网卡
2. 使用 ping 命令测试目标 IP 是否可达
3. 使用 root 权限运行或添加网络能力

### Q2: 任务执行失败，提示 "端口已被占用"？

**原因**: 指定的源端口已被其他进程使用

**解决方法**:
1. 使用 `netstat -tlnp | grep <port>` 查看端口占用
2. 更换其他源端口
3. 停止占用端口的进程

### Q3: 性能达不到预期？

**可能原因**:
1. Worker 数量不足
2. 缓冲区太小
3. CPU 或内存资源不足

**解决方法**:
1. 增加 Worker 数量（在配置文件中调整）
2. 增加缓冲区大小
3. 升级硬件资源

### Q4: WebSocket 连接断开？

**可能原因**:
1. 网络不稳定
2. 超时设置过短
3. 服务端重启

**解决方法**:
1. 检查网络连接
2. 调整超时设置
3. 实现自动重连机制

### Q5: 如何修改登录密码？

**步骤**:
1. 登录系统
2. 点击右上角用户头像
3. 选择 "个人设置"
4. 点击 "修改密码"
5. 输入旧密码和新密码
6. 保存修改

### Q6: 如何查看系统日志？

**方法**:
1. 通过 API: `GET /api/v1/system/logs`
2. 查看文件: `/var/log/trafficgen/app.log`
3. Docker 部署: `docker logs trafficgen`
4. K8s 部署: `kubectl logs <pod-name> -n trafficgen`

### Q7: 数据库文件损坏怎么办？

**解决方法**:
1. 停止服务
2. 从备份恢复数据库文件
3. 或删除损坏的数据库文件，系统会自动创建新数据库
4. 重启服务

### Q8: 如何备份和恢复数据？

**备份**:
```bash
# SQLite 数据库
cp /data/trafficgen.db /backup/trafficgen_$(date +%Y%m%d).db

# 策略配置
curl http://localhost:8080/api/v1/strategies > strategies_backup.json
```

**恢复**:
```bash
# 恢复数据库
cp /backup/trafficgen_20260402.db /data/trafficgen.db

# 重启服务
docker restart trafficgen
```

## 最佳实践

### 1. 任务命名规范

建议使用有意义的命名，包含以下信息:
- 测试目的
- 协议类型
- 目标环境
- 时间戳

示例: `性能测试-TCP-生产环境-20260402`

### 2. 参数配置建议

#### TCP 任务
- 源端口: 使用随机端口或范围（避免冲突）
- MSS: 根据实际网络 MTU 设置（通常 1460）
- 窗口大小: 根据带宽延迟积计算

#### UDP 任务
- 负载大小: 不超过 MTU（1500 字节）
- 发送速率: 根据目标系统处理能力设置

#### HTTP 任务
- Keep-Alive: 启用以提高效率
- 超时时间: 根据实际响应时间设置

### 3. 性能优化

#### 提高吞吐量
- 增加 Worker 数量
- 增大缓冲区
- 使用多任务并发
- 选择高性能网卡

#### 降低延迟
- 减小缓冲区
- 减少 Worker 数量
- 使用实时输出模式

### 4. 安全建议

1. **修改默认密码**: 首次登录后立即修改
2. **使用 HTTPS**: 生产环境必须使用 HTTPS
3. **限制访问**: 通过防火墙限制访问来源
4. **定期备份**: 定期备份数据库和配置
5. **监控日志**: 定期检查系统日志

### 5. 故障排查流程

1. **检查服务状态**: 访问健康检查接口
2. **查看日志**: 检查错误日志
3. **检查资源**: CPU、内存、磁盘、网络
4. **检查配置**: 确认配置文件正确
5. **重启服务**: 尝试重启服务
6. **联系支持**: 提供日志和配置信息

## 附录

### 支持的协议参数

#### TCP 参数
| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| seq | int | 序列号 | 随机 |
| ack | int | 确认号 | 0 |
| window | int | 窗口大小 | 65535 |
| mss | int | 最大分段大小 | 1460 |
| flags | []string | TCP 标志位 | [SYN, ACK] |

#### UDP 参数
| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| length | int | 数据长度 | 0 |
| checksum | bool | 是否计算校验和 | true |

#### HTTP 参数
| 参数 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| method | string | 请求方法 | GET |
| path | string | 请求路径 | / |
| version | string | HTTP 版本 | HTTP/1.1 |
| headers | map | 请求头 | {} |
| body | string | 请求体 | "" |

### 错误代码说明

| 错误代码 | 说明 | 解决方法 |
|---------|------|---------|
| 400 | 请求参数错误 | 检查请求参数格式 |
| 401 | 未认证 | 检查 Token 是否有效 |
| 403 | 权限不足 | 检查用户权限 |
| 404 | 资源不存在 | 检查资源 ID |
| 500 | 服务器内部错误 | 查看服务器日志 |
