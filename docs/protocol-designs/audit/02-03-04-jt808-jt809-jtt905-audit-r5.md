## 2. 第四轮修复验证（J-4.01 ~ J-4.07）

### 2.1 J-4.01：0x1200(SubMsgId=0x01) MsgLength 63→73 修复验证 ✓

**修复位置**：§7B.13 0x1200 hex dump（行 1574）

**修复验证**：
```
修复前：00 00 00 3f (63)
修复后：00 00 00 49 (73)
```

**验算**：
- 消息头 = 32 字节（MsgLength 4 + MsgSN 4 + MsgId 2 + VehicleColor 1 + VehiclePlate 21）
- 消息体 = 1(SubMsgId) + 2(SubLength) + 38(SubBody) = 41 字节
- SubBody = TerminalPhone(6) + ManufacturerId(5) + TerminalModel(20) + TerminalId(7) = 38 字节
- **总计 = 32 + 41 = 73 = 0x49** ✓

**验证结果**：已正确修复。注释 `MsgLength=73 (32 + 1 + 2 + 38 = 73)` 自洽。

---

### 2.2 J-4.02：0x1202 MsgLength 53→63 修复验证 ✓

**修复位置**：§7B.13 0x1202 hex dump（行 1593）

**修复验证**：
```
修复前：00 00 00 35 (53)
修复后：00 00 00 3f (63)
```

**验算**：
- 消息头 = 32 字节
- 消息体 = 1(SubMsgId) + 2(SubLength) + 28(SubBody) = 31 字节
- SubBody = JT808 0x0200 消息体 = 4+4+4+4+2+2+2+6 = 28 字节
- **总计 = 32 + 31 = 63 = 0x3f** ✓

**验证结果**：已正确修复。注释 `MsgLength=63 (32 + 1 + 2 + 28 = 63)` 自洽。

---

### 2.3 J-4.03：B-35 测试断言同步更新验证 ✗

**修复位置**：§8B B-35（行 1671）

**期望修复**：B-35 断言应同步更新为 `0x1200(SubMsgId=0x01) MsgLength=73；0x1202 MsgLength=63`

**实际检查**：
```markdown
| B-35 | msglength_correct | wire-format | 0x1001 MsgLength=57；0x1002 MsgLength=37；
  0x1200(SubMsgId=0x01) MsgLength=63；0x1202 MsgLength=53。
  每条报文 MsgLength = 32(头) + body length（精确数值断言） |
```

**问题**：B-35 测试用例描述中的 `0x1200(SubMsgId=0x01) MsgLength=63；0x1202 MsgLength=53` **未同步更新**！

- 0x1200(SubMsgId=0x01) 应为 **73**（非 63）
- 0x1202 应为 **63**（非 53）

**严重度**：HIGH（测试期望与 hex dump 不一致，实现者按 63/53 写测试会失败，按 73/63 写测试与用例描述不符）

**修复建议**：
```markdown
0x1200(SubMsgId=0x01) MsgLength=73；0x1202 MsgLength=63
```

### 2.4 J-4.04：0x8001 MsgSN 0→2 + 校验码 0x24 修复验证 ✓

**MsgSN=2 语义验证**：
- check-in 应答 SN=0
- heartbeat1 应答 SN=1
- heartbeat2 应答 SN=2（本例）
- 与 §6C.2 "platformMsgSN 独立递增"一致 ✓

**验证结果**：已正确修复。

## 6. 其他发现问题

### 6.1 MEDIUM-1：JT809 §6B.3 未明确 PlatformInitialSN 术语

**位置**：§6B.3（行 1398-1399）

**问题**：JT809 使用 "InitialSN" 但 JTT905 §6C.2 明确区分 "InitialSN"（ISU 侧）与 "PlatformInitialSN"（平台侧）。JT809 应同步明确 "mainMsgSN/slaveMsgSN 初值=InitialSN，首条消息 SN=InitialSN；平台侧独立计数器 platformMainMsgSN/platformSlaveMsgSN 初值=PlatformInitialSN（默认 0）"。

**修复建议**：同步 JTT905 表述。

---

### 6.2 MEDIUM-2：B-58 测试用例描述与 §11.2 映射表不一致

**位置**：§8B B-58（行 1668）

**问题**：B-58 描述为 "JT809 VehiclePlate GBK 编码后左对齐空格填充至 21 字节"，但 §11.2 映射表（行 2517）明确区分 PadRightSpace（0x20）与 PadRightGBK（0x00）。测试描述未明确断言填充字节 = 0x20。

**修复建议**：B-58 描述增加 "断言填充字节 = 0x20（与 PadRightGBK 0x00 填充明确区分）"。

### 6.5 LOW-2：§16.4 与 §16.5 编号格式不一致

