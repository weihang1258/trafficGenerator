## 优先级建议

按业务价值与技术难度综合排序：

**P0（最常用，优先实现）**：
- MQTT（IoT 最常见）
- TFTP（嵌入式/网络设备常用）
- MODBUS（工控事实标准）
- SMB（Windows 文件共享事实标准）
- TDS（SQL Server 事实标准）

**P1（车联网批量）**：
- GBT32960、JT808、JT809、JTT905、DOIP（车联网一揽子）

**P2（长尾）**：
- NFS、RIP、DNP3、ENIP、SRV6
- MCP、A2A（Agent 流量解析，与本项目自身 MCP 服务器区分）

## 备注

1. **MCP（扩展表 31）** 与本项目 `internal/mcp/` 不同：
   - `internal/mcp/` = 本系统作为 MCP 服务器供 LLM 调用（出方向）
   - 扩展表 31 = 把 MCP 当作被解析/生成的网络流量协议（入方向）
   - 两者不冲突，但需新写 `internal/protocol/mcp/` 解析器
2. **DHCPv6** 不在扩展表 16 覆盖范围（表 16 是 DHCPv4 语义）。
3. **NDP** 字段已在扩展表 17（ICMP）中包含，本项目 `icmpv6/` 已覆盖。
