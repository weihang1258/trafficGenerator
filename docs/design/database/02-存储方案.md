# 数据库设计 - 存储方案

**文档版本**: v1.0  
**更新日期**: 2026-04-01

---

## 1. 存储选型

| 数据类型 | 存储方案 | 理由 |
|---------|---------|------|
| 任务/策略 | SQLite/PostgreSQL | 结构化数据，事务支持 |
| 实时状态 | Redis | 高性能读写 |
| 时序指标 | Prometheus | 专业时序数据库 |
| 配置文件 | YAML | 易读易写 |

---

## 2. SQLite vs PostgreSQL

### 开发环境：SQLite
- 无需安装
- 单文件存储
- 轻量级

### 生产环境：PostgreSQL
- 高并发支持
- 完整事务
- 丰富特性

## 3. 数据库连接

```go
// internal/storage/db.go
import (
    "database/sql"
    _ "github.com/mattn/go-sqlite3"
)

func NewDB(dsn string) (*sql.DB, error) {
    db, err := sql.Open("sqlite3", dsn)
    if err != nil {
        return nil, err
    }
    return db, nil
}
```

## 4. Repository模式

```go
type TaskRepository interface {
    Create(task *Task) error
    Get(id string) (*Task, error)
    List(filter Filter) ([]*Task, error)
    Update(task *Task) error
    Delete(id string) error
}

type taskRepo struct {
    db *sql.DB
}

func (r *taskRepo) Create(task *Task) error {
    _, err := r.db.Exec(
        "INSERT INTO tasks (id, name, spec, status) VALUES (?, ?, ?, ?)",
        task.ID, task.Name, task.Spec, task.Status,
    )
    return err
}
```
