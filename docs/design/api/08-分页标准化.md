**更新日期**: 2026-04-01

## 统一分页参数

### 请求参数
```
GET /api/v1/tasks?page=1&size=20&sort=created_at&order=desc
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| page | int | 1 | 页码（从1开始）|
| size | int | 20 | 每页数量（最大100）|
| sort | string | created_at | 排序字段 |
| order | string | desc | 排序方向（asc/desc）|

### 响应格式
```json
{
  "code": 0,
  "data": {
    "items": [...],
    "pagination": {
      "page": 1,
      "size": 20,
      "total": 100,
      "total_pages": 5
    }
  }
}
```
