## 1. 部署架构

```
┌─────────────────────────────────────┐
│      Load Balancer (可选)           │
└──────────────┬──────────────────────┘
               │
    ┌──────────┴──────────┐
    │                     │
┌───▼────┐          ┌────▼───┐
│ Node 1 │          │ Node 2 │
│ (主节点)│          │(备节点)│
└────┬───┘          └────┬───┘
     │                   │
     └────────┬──────────┘
              │
    ┌─────────▼─────────┐
    │   Redis Cluster   │
    └───────────────────┘
```

---

## 2. 单机部署

**适用场景**：开发、测试环境

**配置**：
- CPU: 4核
- 内存: 8GB
- 磁盘: 50GB

---

## 3. 集群部署

**适用场景**：生产环境

**配置**：
- 节点数: 2+
- 负载均衡: Nginx/HAProxy
- 数据库: PostgreSQL主从
- 缓存: Redis Cluster

---

## 4. 高可用方案

- 主备切换
- 健康检查
- 自动故障转移
