# 部署方案 - Kubernetes部署

**文档版本**: v1.0  
**更新日期**: 2026-04-01

---

## 1. Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: traffic-generator
spec:
  replicas: 2
  selector:
    matchLabels:
      app: traffic-generator
  template:
    metadata:
      labels:
        app: traffic-generator
    spec:
      containers:
      - name: traffic-generator
        image: traffic-generator:v2.0.0
        ports:
        - containerPort: 8080
        - containerPort: 9090
        resources:
          requests:
            memory: "256Mi"
            cpu: "500m"
          limits:
            memory: "1Gi"
            cpu: "2000m"
        env:
        - name: DB_HOST
          value: postgres
        - name: REDIS_HOST
          value: redis
```

---

## 2. Service

```yaml
apiVersion: v1
kind: Service
metadata:
  name: traffic-generator
spec:
  selector:
    app: traffic-generator
  ports:
  - name: http
    port: 8080
    targetPort: 8080
  - name: grpc
    port: 9090
    targetPort: 9090
  type: LoadBalancer
```

---

## 3. ConfigMap

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: traffic-generator-config
data:
  config.yaml: |
    server:
      port: 8080
    engine:
      config_workers: 4
      packet_workers: 4
```

---

## 4. 部署命令

```bash
# 应用配置
kubectl apply -f deployment.yaml
kubectl apply -f service.yaml
kubectl apply -f configmap.yaml

# 查看状态
kubectl get pods
kubectl get svc

# 查看日志
kubectl logs -f deployment/traffic-generator
```
