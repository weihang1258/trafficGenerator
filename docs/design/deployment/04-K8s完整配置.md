# 部署方案 - Kubernetes部署

**文档版本**: v1.0  
**更新日期**: 2026-04-01

---

## 1. Deployment

```yaml
# k8s/deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: traffic-generator
  namespace: default
spec:
  replicas: 2
  selector:
    matchLabels:
      app: traffic-generator
  template:
    metadata:
      labels:
        app: traffic-generator
    spec:
      containers:
      - name: traffic-generator
        image: traffic-generator:v2.0.0
        ports:
        - containerPort: 8080
          name: rest
        - containerPort: 9090
          name: grpc
        - containerPort: 9091
          name: metrics
        env:
        - name: TG_DATABASE_TYPE
          value: "postgres"
        - name: TG_DATABASE_HOST
          value: "postgres-service"
        - name: JWT_SECRET
          valueFrom:
            secretKeyRef:
              name: tg-secrets
              key: jwt-secret
        resources:
          requests:
            memory: "256Mi"
            cpu: "500m"
          limits:
            memory: "1Gi"
            cpu: "2000m"
        livenessProbe:
          httpGet:
            path: /health
            port: 8080
          initialDelaySeconds: 30
          periodSeconds: 10
        readinessProbe:
          httpGet:
            path: /ready
            port: 8080
          initialDelaySeconds: 5
          periodSeconds: 5
```

## 2. Service

```yaml
# k8s/service.yaml
apiVersion: v1
kind: Service
metadata:
  name: traffic-generator-service
spec:
  selector:
    app: traffic-generator
  ports:
  - name: rest
    port: 8080
    targetPort: 8080
  - name: grpc
    port: 9090
    targetPort: 9090
  type: ClusterIP
```

---

## 3. Ingress

```yaml
# k8s/ingress.yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: traffic-generator-ingress
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  rules:
  - host: tg.yourdomain.com
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: traffic-generator-service
            port:
              number: 8080
```

## 4. ConfigMap

```yaml
# k8s/configmap.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: tg-config
data:
  config.yaml: |
    server:
      rest_port: 8080
      grpc_port: 9090
    engine:
      config_workers: 4
      packet_workers: 4
    logging:
      level: info
```

---

## 5. Secret

```yaml
# k8s/secret.yaml
apiVersion: v1
kind: Secret
metadata:
  name: tg-secrets
type: Opaque
data:
  jwt-secret: <base64-encoded-secret>
  db-password: <base64-encoded-password>
```

创建:
```bash
kubectl create secret generic tg-secrets \
  --from-literal=jwt-secret=your-secret \
  --from-literal=db-password=your-password
```

---

## 6. 部署命令

```bash
# 应用所有配置
kubectl apply -f k8s/

# 查看状态
kubectl get pods -l app=traffic-generator
kubectl get svc traffic-generator-service

# 查看日志
kubectl logs -f deployment/traffic-generator

# 扩容
kubectl scale deployment traffic-generator --replicas=3
```
