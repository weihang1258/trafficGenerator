## 2. 模块划分

### 2.1 核心模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| **Engine** | 主控制器，生命周期管理 | Worker, Buffer |
| **Worker Pool** | Goroutine池管理 | Channel |
| **Ring Buffer** | 环形缓冲区 | Sync |
| **Rate Limiter** | 速率限制器 | Sync |
| **Protocol Registry** | 协议注册中心 | - |

### 2.2 协议模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| **TCP Planner** | TCP流规划 | Builders |
| **UDP Planner** | UDP流规划 | Builders |
| **HTTP Planner** | HTTP会话规划 | TCP, Generators |
| **DNS Planner** | DNS查询规划 | UDP, Builders |

### 2.3 API模块

| 模块 | 职责 | 依赖 |
|------|------|------|
| **REST Server** | HTTP API服务 | Gin, Engine |
| **gRPC Server** | gRPC服务 | gRPC, Engine |
| **MCP Server** | MCP协议服务 | Engine |
| **WebSocket** | 实时推送 | Gorilla, Engine |

## 4. 并发模型

### 4.1 Goroutine设计

```go
// 配置生成池
for i := 0; i < numConfigWorkers; i++ {
    go configWorker(taskChan, configChan)
}

// 报文构造池
for i := 0; i < numPacketWorkers; i++ {
    go packetWorker(configChan, packetChan, rateLimiters)
}

// 采集器
go collector(packetChan, buffer)

// 监控器
go metricsCollector()
```

### 4.2 Channel设计

```go
taskChan   := make(chan Task, 1000)        // 任务队列
configChan := make(chan PacketConfig, 2000) // 配置队列
packetChan := make(chan []byte, 2000)       // 报文队列
```

## 5. 数据流

### 5.1 任务提交流程

```
用户 → REST API → Engine → Task Queue
                              ↓
                    Config Worker Pool
                              ↓
                    Config Channel
                              ↓
                    Packet Worker Pool
                              ↓
                    Packet Channel
                              ↓
                    Collector
                              ↓
                    Ring Buffer
                              ↓
                    API Response
```

### 5.2 实时监控流程

```
Engine Metrics → Prometheus Collector
                        ↓
                 Prometheus Server
                        ↓
                 WebSocket Push
                        ↓
                 Web UI Update
```

## 6. 技术决策

### 6.1 为什么选择Go？

| 优势 | 说明 |
|------|------|
| **高性能** | 编译型语言，接近C性能 |
| **并发优秀** | Goroutine轻量级，百万级并发 |
| **内存效率** | 无GIL，真正的并行 |
| **部署简单** | 单二进制文件 |
| **生态成熟** | 网络库丰富 |

### 6.2 为什么选择Vue 3？

| 优势 | 说明 |
|------|------|
| **渐进式** | 易上手，灵活 |
| **性能好** | Composition API，响应式优化 |
| **生态好** | Element Plus等成熟组件库 |
| **TypeScript** | 类型安全 |

## 7. 扩展性设计

### 7.1 协议扩展

添加新协议只需2步：

```go
// 1. 实现协议规划函数
func PlanDNSFlow(spec FlowSpec) <-chan PacketConfig {
    // 实现逻辑
}

// 2. 注册协议
func init() {
    protocols.Register("dns", PlanDNSFlow)
}
```

### 7.2 API扩展

添加新接口：

```go
// REST API
router.POST("/api/v1/new-endpoint", handler)

// gRPC
service.RegisterNewService(server, impl)
```
