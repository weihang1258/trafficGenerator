## 1. Prometheus指标

```go
// internal/metrics/prometheus.go
var (
    TasksTotal = promauto.NewCounter(prometheus.CounterOpts{
        Name: "traffic_tasks_total",
        Help: "Total number of tasks",
    })
    
    PacketsGenerated = promauto.NewCounter(prometheus.CounterOpts{
        Name: "traffic_packets_generated_total",
        Help: "Total packets generated",
    })
    
    BytesGenerated = promauto.NewCounter(prometheus.CounterOpts{
        Name: "traffic_bytes_generated_total",
        Help: "Total bytes generated",
    })
    
    BufferUsage = promauto.NewGauge(prometheus.GaugeOpts{
        Name: "traffic_buffer_usage_percent",
        Help: "Buffer usage percentage",
    })
)
```

## 2. Zap日志

```go
// internal/logging/logger.go
func NewLogger() *zap.Logger {
    config := zap.NewProductionConfig()
    config.OutputPaths = []string{"stdout", "/var/log/traffic-generator.log"}
    logger, _ := config.Build()
    return logger
}

// 使用
logger.Info("Task started",
    zap.String("task_id", taskID),
    zap.String("protocol", protocol),
)
```

## 3. 监控采集

```go
func collectMetrics(engine *core.Engine) {
    ticker := time.NewTicker(5 * time.Second)
    for range ticker.C {
        status := engine.GetStatus()
        BufferUsage.Set(status.BufferUsage)
        PacketsGenerated.Add(float64(status.PacketsDelta))
    }
}
```
