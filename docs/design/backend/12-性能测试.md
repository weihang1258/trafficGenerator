## 2. 测试场景

### 场景1: 单协议压测

```go
// test/performance/tcp_test.go
func TestPerf_TCP_1M_PPS(t *testing.T) {
    engine := setupEngine()
    
    start := time.Now()
    
    // 提交10000个TCP流
    for i := 0; i < 10000; i++ {
        engine.SubmitTask(Task{
            Protocol: "tcp",
            Spec: TCPSpec{
                Packets: 100,
            },
        })
    }
    
    // 等待完成
    time.Sleep(10 * time.Second)
    
    stats := engine.GetStats()
    duration := time.Since(start).Seconds()
    pps := float64(stats.PacketsSent) / duration
    
    t.Logf("PPS: %.0f", pps)
    assert.Greater(t, pps, 1000000.0)
}
```

### 场景2: 混合协议

```go
func TestPerf_Mixed_Protocols(t *testing.T) {
    spec := BatchSpec{
        Classes: []TrafficClass{
            {Type: "tcp", BPS: "400M"},
            {Type: "udp", BPS: "300M"},
            {Type: "http", BPS: "300M"},
        },
    }
    
    runner := engine.StartBatch(spec)
    time.Sleep(60 * time.Second)
    
    stats := runner.GetStats()
    assert.Greater(t, stats.TotalBPS, 900000000.0)
}
```

## 3. 工具选型

### 3.1 Go基准测试

```bash
go test -bench=. -benchmem -cpuprofile=cpu.prof ./pkg/core
go tool pprof cpu.prof
```

### 3.2 Vegeta (HTTP压测)

```bash
echo "POST http://localhost:8080/api/v1/tasks" | \
  vegeta attack -duration=60s -rate=1000 | \
  vegeta report
```

### 3.3 Prometheus监控

```yaml
# 监控指标
- tg_packet_rate_pps
- tg_buffer_usage_percent
- process_cpu_seconds_total
- process_resident_memory_bytes
```

## 4. 测试脚本

```bash
#!/bin/bash
# test/performance/run_perf_test.sh

echo "=== Performance Test ==="

# 启动服务
./traffic-generator server &
PID=$!
sleep 5

# 运行测试
go test -v -timeout=30m ./test/performance/

# 收集指标
curl http://localhost:9091/metrics > metrics.txt

# 清理
kill $PID

echo "Test completed"
```
