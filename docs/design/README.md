## 阅读顺序建议

### 新成员入门
1. 项目概述 → 系统架构
2. 核心引擎 → 协议层
3. REST API → 页面设计

### 后端开发
1. 核心引擎 → 协议层 → 报文构造
2. 参数生成器 → 批量处理
3. REST API → gRPC API

### 前端开发
1. 技术栈 → 页面设计
2. 组件设计 → 状态管理
3. REST API → WebSocket

### 运维部署
1. 系统架构 → 部署架构
2. Docker部署 → K8s部署
3. 参考 `trafficgen/deployments/DEPLOYMENT.md` 获取完整部署指南

## 文档规范

### 文档模板

每个设计文档应包含：

```markdown
# 模块名称

## 1. 概述
- 模块职责
- 核心功能

## 2. 设计目标
- 性能目标
- 质量目标

## 3. 详细设计
- 数据结构
- 接口定义
- 实现细节

## 4. 示例代码

## 5. 测试要点

## 6. 注意事项
```

### 更新规范

- 每次修改需更新文档头部的"更新日期"
- 重大变更需在文档中标注版本号
- 保持文档与代码同步
