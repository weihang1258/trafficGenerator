## 输出层设计要点

### 1. 输出模式
- `interface` - 网卡发送
- `pcap` - PCAP文件
- `both` - 同时输出
- `callback` - 回调函数（扩展）

### 2. 核心组件
- `OutputWriter` 接口
- `InterfaceWriter` - 网卡输出
- `PcapWriter` - 文件输出
- `OutputManager` - 输出管理器

### 3. 与引擎集成
- 从Ring Buffer批量读取
- 通过OutputManager分发
- 支持多网卡并发输出

```
Task → ConfigWorker → PacketWorker → RingBuffer → OutputWorker → [网卡/PCAP]
```
