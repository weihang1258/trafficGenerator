# 前端设计 - 页面设计

**文档版本**: v1.0  
**更新日期**: 2026-04-01

---

## 1. 页面列表

| 页面 | 路由 | 功能 |
|------|------|------|
| 概览 | /dashboard | 系统总览 |
| 任务 | /tasks | 任务管理 |
| 策略 | /strategies | 策略管理 |
| 协议 | /protocols | 协议配置 |
| 监控 | /monitor | 实时监控 |
| 设置 | /settings | 系统设置 |

---

## 2. 概览页面

**组件**：
- StatCard: 统计卡片
- RealtimeChart: 实时图表
- TaskList: 任务列表

---

## 3. 任务页面

**功能**：
- 任务列表（表格）
- 创建任务（对话框）
- 任务详情（抽屉）
- 启动/停止操作

---

## 4. 策略页面

**功能**：
- 策略卡片列表
- 创建/编辑策略
- 策略导入/导出

---

## 5. 监控页面

**图表**：
- 流量趋势（折线图）
- 报文速率（面积图）
- 协议分布（饼图）
- CPU使用率（仪表盘）
