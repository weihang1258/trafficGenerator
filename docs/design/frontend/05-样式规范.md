## 1. 颜色规范

```css
:root {
  --primary-color: #409EFF;
  --success-color: #67C23A;
  --warning-color: #E6A23C;
  --danger-color: #F56C6C;
  --info-color: #909399;
  
  --bg-color: #F5F7FA;
  --text-primary: #303133;
  --text-regular: #606266;
  --text-secondary: #909399;
}
```

## 2. 间距规范

